# Code of Conduct

This project follows the Contributor Covenant Code of Conduct, version 2.1.

Be respectful, constructive, and focused on improving the project. Harassment, personal attacks, and abusive behavior are not acceptable.

Maintainers may remove comments, issues, pull requests, or contributors that violate this policy.

The full text is available at:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/
