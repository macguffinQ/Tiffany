# Contributor License

Tiffany Loop does not currently require a separate contributor license
agreement.

Contributions are handled through the repository's Apache-2.0 license and the
normal pull request process. Before opening a pull request, read the root
[`CONTRIBUTING.md`](../../CONTRIBUTING.md) and confirm that:

- you have the right to submit the change;
- the change is compatible with Apache-2.0;
- no private config, API key, session log, database, or generated worktree is
  included.

The `tiffany-ui/` directory contains upstream-derived UI code. Preserve upstream
license headers and attribution when changing forked files.
